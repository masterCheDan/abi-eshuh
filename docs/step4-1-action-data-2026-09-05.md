# 第四步 4.1：普攻数据与动作规则预检

## 本轮交付范围

按子阶段交付，本轮仅完成数据保留、动作契约和缺口检查基础设施。**没有认证任何学生可以可信自动排轴，也没有实现动作执行器。** 扣弹、完成、补弹、打断恢复等游戏时点仍待核实，不能将本报告当作第四步整体验收。

- Normal 现在完整保留为运行时 Skills.N，不再经过会丢字段的精简逻辑；包括 Effects、任意深度 FormChange、FixedFrameRate、Radius 和额外伤害修正字段。
- 272 名学生中，185 名有普攻数据，另有 12 个变身普攻分支，共 197 个动作数据节点、226 条效果。其余 87 名没有 Normal 数据，检查器不会补默认循环。
- 普攻类型新增效果、变身分支、固定帧率、范围和属性修正结构。Effects 可选仅为兼容旧数据/测试输入；检查器把缺失视为数据错误，而非“无需效果即可自动攻击”。
- 普攻伤害段的 Hits 保持原始数组，不转换为攻击次数；Ammo 和 AmmoCost 独立保留。
- 共享目录新增 actions v1，经 GameRules.action.inspect 和覆盖命令调用同一预检实现。这个版本是**动作数据规则版本**，不是尚未实现的 v5 调度/分享版本。
- 既有 EX、NS、开局效果的执行方式不变；未改变 UI、用户事实、分享格式或模拟时序。

## 规则与未决事项

数据契约明确：完成记录才可推进一次普攻计数，不能用 Hits 长度替代；AmmoCost 是弹药量来源；失败施放不得修改动作；已生效效果在中断后保留。这些是后续执行器的约束，本轮不宣称已在旧普攻推算器中执行。

以下时序无法仅凭现有原始结构认证，逐学生列出阻碍，不使用近似默认值：

| 检查点 | 尚缺的规则 |
| --- | --- |
| ammoDebit | 扣弹时点、点射被打断后的实际消耗 |
| attackComplete | 动画分段数据到动作完成帧的确定映射 |
| reloadRefill | 实际补弹时点及中断换弹是否保留进度 |
| interruptResume | EX、NS、控制后的准备、攻击、换弹恢复 |
| pendingEffectsOnInterrupt | 尚未生效效果的取消/保留策略 |
| frameComposition | 各动画阶段如何组合，攻速影响哪些阶段 |

附加依赖从学生技能及深层 ExtraSkills、开局合成效果中检查：攻速、弹匣、忽略间隔、位移/射程、控制、特殊状态与普攻替换。不将未知 Special 当作“对动作无影响”。

这是学生数据层预检，不检查实际队伍中其他学生授予的活动效果、站位或当前技能配置；后续队伍级自动资格必须在此基础上继续验证。当前所有结果明确为 automaticEligible=false，无“修改登记状态即可打开自动”的通路。

## 覆盖门禁

- 普攻和递归 FormChange 的 Effect、Target、Stat、Condition 等也进入现有登记检查；不扩展公开 SkillRef。
- Normal 字段、帧数据、StatModifier 的来源、普攻伤害类型替换、范围、正整数 Ammo/AmmoCost 受检。未知字段会保留在生成产物里并导致检查失败，不会先被构建器删掉。
- 新发现樱子 10061 的 Special:SilverBullet / Equal、昴 10130 的 Special:CH0309_Ex 条件，显式登记为 state_only；未执行普攻条件分支及其后续战斗影响。
- 动作目录处理器必须有真实绑定；版本未知、缺少限制、非法引用和冒充 implemented 均失败。
- 保留 check:effects 命令；文本和 --json 增加动作预检与准确路径。登记通过不代表动作可自动执行。

当前登记/使用位置统计：implemented 2299、manual_fact 907、state_only 1498、partial 2775，错误 0。数量是登记使用位置，不是已完成技能数。动作预检覆盖 272 名学生，开放自动资格 0。

- 现有未知字段参数化用例同时检查 EX 和 Normal；处理器缺失回归同时覆盖动作预检。
- 新增 5 个用例，覆盖弹药与段数分离、变身与合成替换依赖、缺失/非法数据、深层未知字段、版本/契约/登记配置失败。未增加逐学生重复测试。
- 全量 225 项测试通过（原有 220 项继续通过）；类型检查、Lint、规则登记和生产构建通过。Node v24.19.0。
- 生产 JS 515.37 kB，仍有超过 500 kB 的打包提示；本阶段不做打包优化。
- 未变动 UI，因此本轮没有做浏览器动作交互验收；自动模式和动作轨道必须在后续子阶段验收。
- 既有 fsm.ts 文件末尾空行提示未处理，与本轮无关。
